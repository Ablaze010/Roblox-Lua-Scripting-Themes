# 🎮 Roblox Luau Scripting

**A learning resource and development portfolio dedicated to Roblox scripting with Luau.**

Welcome! This repository contains scripting guides, practical code examples, and projects designed to demonstrate and develop Roblox development skills — from the fundamentals to advanced programming concepts.

Whether you're learning your first variables or exploring server-client architecture, this repository aims to make Roblox scripting easier to understand.

---

## 📚 Guides

Learn Luau step by step through three levels.

| Guide | Description | Level |
|---|---|---|
| [Beginner Guide](guides/beginner.md) | Variables, functions, conditions, loops, and events | 🟢 Beginner |
| [Intermediate Guide](guides/intermediate.md) | ModuleScripts, RemoteEvents, tables, and reusable systems | 🟡 Intermediate |
| [Professional Guide](guides/professional.md) | Architecture, security, persistence, and optimization | 🔴 Advanced |

*More guides and practical examples will be added over time.*

## 🛠️ Projects

This repository will feature practical Roblox systems that demonstrate how Luau works in real games.

| Project | Description | Status |
|---|---|---|
| Coin Collection System | Collectible coins and server-side rewards | 🔨 Planned |
| Inventory System | Store and manage player items | 🔨 Planned |
| Shop System | Purchase items using in-game currency | 🔨 Planned |
| Round System | Manage waiting, active, and ended rounds | 🔨 Planned |
| Data Saving | Save and load player progress | 🔨 Planned |

Each project will include setup instructions, code explanations, and information about how the system works.

The main goals of this repository are to:
